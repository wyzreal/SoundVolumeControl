# App icon

`AppIcon.png` is the original image with transparency, generated using the built-in image generation tool. `AppIcon.icns` contains macOS icon sizes from 16 to 1024 pixels, converted with `sips` and `iconutil`. The Makefile embeds it in the app's Resources folder.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for SoundVolumeControl, a small native volume utility. Create one polished square 1024x1024 icon, straight-on, centered. A softly rounded macOS squircle tile with a deep graphite-to-slate subtle gradient, tactile satin surface and restrained dimensional bevel. In the center a large beautifully simple pearl-white speaker silhouette with two clean curved sound waves, subtly embossed, readable at small sizes. A single tiny cool silver highlight adds precision; calm, understated premium native utility design. Tile occupies about 86% of canvas width with even margins. Real transparent background outside the rounded tile, retain alpha, subtle tight shadow only. No text, letters, numbers, branding, decorative equalizer bars, extra objects, presentation mockup, border frame, or watermark.
